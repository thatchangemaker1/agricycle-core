# AgriCycle-Core
USSD logic simulation for the AgriCycle biochar and carbon credit ledger prototype.

## Overview
AgriCycle leverages mobile technology (USSD) to connect smallholder farmers with sustainable waste management and carbon credit markets.

## Files
- `agricycle_sim.py`: Core Python script simulating the interactive USSD workflow.

## How to Run
1. Clone or download the repository.
2. Open the script in Python or Google Colab.
3. Run `agricycle_sim.py` to test the interactive USSD menu.
